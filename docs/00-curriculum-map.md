# Master Curriculum Map — Algerian Secondary English (1AS / 2AS / 3AS)

> **Source fidelity statement.** This curriculum map is derived **only** from
> the official Algerian Ministry of National Education syllabus documents
> (annual distribution + teaching map). Every theme, unit, project, productive-
> language item, time allocation, and stream variant below is traceable to those
> sources (see `docs/02-source-attribution.md`). Nothing has been invented.

---

## 1. Three communicative competencies (the CBA spine)

The Algerian secondary English syllabus organises ALL learning around three
communicative competencies — referenced in the official Teaching Map as
**C1 / C2 / C3** at the head of every unit aim:

| Code | Competency | Definition (per syllabus) | Typical aim verbs |
|------|------------|---------------------------|-------------------|
| **C1** | **Interaction** | The learner negotiates meaning in real time with one or more interlocutors (oral or written). | guess, respond, ask, answer, agree, disagree, justify, request, instruct, salutation |
| **C2** | **Production / Expression** | The learner produces an extended, organised oral or written text for a purpose and an audience. | describe, narrate, report, expose, argue, write, deliver, present |
| **C3** | **Interpretation** | The learner extracts, infers and interprets meaning from oral or written input. | predict, skim, scan, infer, summarise, interpret a graph / blurb / picture |

Every unit objective in this curriculum is tagged **(C1)**, **(C2)** or **(C3)**.

---

## 2. The five pillars of the syllabus (officially mandated)

These are the non-negotiable design pillars taken from the Teaching Map
guidelines section.

1. **Project-Based Learning.** Every unit has a culminating *Project /
   Portfolio*. The project is the unit's reason to exist; activities are
   *judiciously selected so as to target the project*.
2. **The Six A's of Project Design.**
   1. **A**uthenticity — problem has meaning to the learner and the community.
   2. **A**cademic Rigor — discipline-grounded knowledge & higher-order thinking.
   3. **A**pplied Learning — semi-structured, real-world problems.
   4. **A**ctive Exploration — field-based work and varied media.
   5. **A**dult Connections — exposure to expert voices outside school.
   6. **A**ssessment Practices — exemplars, milestones, timely feedback,
      structured self-assessment.
3. **Engage – Study – Activate** lesson cycle (Callum Robertson, BBC English,
   adapted by Mr. Allouane in the source document).
4. **Six unit phases** (replicated in every textbook unit):
   *Listen & Consider · Read & Consider · Listening & Speaking · Reading &
   Writing · Write It Up · Write It Out* (a.k.a. *Stop & Consider /
   Anticipate / Your Turn / Practice* in the 1AS book).
5. **Integrated four skills** with explicit *productive language* (grammar +
   functional expressions) listed for every task.

## 7. Assessment system (mandated by official syllabus)

The official annual distribution explicitly schedules three written exams
(*اختبارات الثلاثي الأول/الثاني/الثالث*). On top of that, this curriculum
adds a layered formative system aligned with **Six A's > Assessment Practices**:

| Assessment type | Where in the year | Purpose | Tool |
|-----------------|-------------------|---------|------|
| **Diagnostic** | Week 1 of each grade | Establish a baseline | Entry test + skills checklist |
| **Formative — micro** | Every lesson | Adjust on the fly | Exit ticket, observation checklist, peer-feedback card |
| **Formative — meso** | Each unit phase | Confirm phase mastery | Phase quiz, portfolio milestone |
| **Summative — unit** | End of each unit | Certify unit competency | Unit test (R-W-L-S) + project rubric |
| **Summative — trimester** | End of T1, T2, T3 | Official Ministry exam | Trimester exam blueprint + answer key |
| **Performance task** | 2× per trimester | Demonstrate transfer | Authentic task + analytic rubric |

### 7.1 Performance-task pattern (Backward Design alignment)

For every unit we ship one *culminating performance task* identical in spirit
to the textbook project. This satisfies Backward Design Stage 2 (acceptable
evidence) and the Six A's Authenticity criterion.

## 8. Bloom's taxonomy alignment

Every lesson objective in this curriculum is written with a Bloom's verb
followed by an explicit competency tag and a measurable behaviour:

```
By the end of the lesson, students will be able to <BLOOM-VERB> <CONTENT>
                          using <PRODUCTIVE LANGUAGE> in <CONTEXT>. (Cx)
```

The six Bloom's levels are mapped to typical Algerian-syllabus actions:

| Bloom's level | Sample verbs | Typical activities in this curriculum |
|---------------|--------------|---------------------------------------|
| **Remember** | recall, define, list, identify, label | Vocabulary recall, glossary recognition, fact retrieval |
| **Understand** | explain, summarise, paraphrase, classify, interpret | Reading & listening *Anticipate / As you read*, summarising for C3 |
| **Apply** | use, demonstrate, complete, illustrate, perform | *Practice* phase, *Write it right*, gap-fills, role-plays |
| **Analyse** | compare, contrast, differentiate, examine, organise | *Discovering language* tasks, *Stop & Consider*, comparing past/present lifestyles |
| **Evaluate** | judge, justify, critique, defend, assess | *Your turn*, opinion articles, peer review, project rubric self-assessment |
| **Create** | design, compose, produce, plan, construct | The unit project itself: CV, book review, survey report, invention profile, etc. |

## 9. Backward-Design template (used for every unit)

Every unit in this package is built in three Backward-Design stages so that
**objectives ⇄ activities ⇄ assessments are always aligned**:

1. **Stage 1 — Desired results.** Pull the unit's official competency, theme,
   project, productive language, and skills directly from the Teaching Map.
   Convert into 4–8 measurable Bloom's-tagged objectives.
2. **Stage 2 — Acceptable evidence.** Define the project artefact, the unit
   test blueprint, and the formative checkpoints that will demonstrate each
   objective.
3. **Stage 3 — Learning experiences.** Sequence ESA lessons (Engage / Study /
   Activate) across the six unit phases (Listen & Consider, Read & Consider,
   Listening & Speaking, Reading & Writing, Write It Up, Write It Out) so
   that every activity targets at least one objective.

Per-lesson alignment is recorded in a **Competency × Objective × Activity ×
Assessment** matrix in the lesson plan header. Lessons that do not pass the
matrix check are revised before publication (see `docs/04-quality-assurance.md`).

## 10. Differentiation (Phase 8 preview)

Every unit ships with a differentiation sheet covering four learner profiles,
all anchored to the same competencies:

| Learner profile | Strategy |
|-----------------|----------|
| Struggling learner | Reduced text length, sentence frames, bilingual glossary, paired work, scaffolded outline for the project |
| ADHD-friendly | Chunked timing (Pomodoro 8/2 mins), movement breaks, single-task instructions, visual schedule, choice boards, fidget-friendly layout |
| Advanced learner | Stretch tasks (debate, op-ed, podcast), independent research, cross-unit synthesis, open-ended project extension |
| Inclusive classroom | Universal Design for Learning (multiple means of engagement, representation, action & expression), buddy system, translanguaging when productive |
