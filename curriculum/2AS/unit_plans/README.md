## What this folder will contain

For the 2AS Foreign Languages stream **only** — never for any other
stream (Stream Integrity Rule, `../../../docs/01-pedagogical-framework.md`
Section 1.b). Each unit overview is **Backward Design Stage 1 + Stage 2**:
desired results + acceptable evidence. Stage 3 (learning experiences) is
deferred to lesson plans (a later phase).

The 6 unit-overview files use the strict teaching order from the Annual
Distribution PDF (Reading A confirmed by user 2026-06-17): textbook
units **1 → 2 → 3 → 4 → 7 → 6**. The textbook unit number is preserved
in the filename so teachers can match pages in *Getting There*.

## Template

Each unit-overview file will be authored to the structure defined in
[`_template-unit-overview.md`](_template-unit-overview.md). The template
is **completely generic** — it contains no 2AS-specific content. It
exists to:

1. Lock in a consistent shape across the 6 unit files when authoring begins.
2. Make explicit which sections are sourced (priority 1–3) versus which
   are pedagogical inference (priority 4 — must be tagged).
3. Preserve the user's no-derivation, no-reorder, no-optimisation rules
   inside every file's header.
