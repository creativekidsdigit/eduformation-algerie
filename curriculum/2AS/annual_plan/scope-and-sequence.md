# 2AS — Foreign Languages — Scope & Sequence

> Per-unit scope (what is taught) and sequence (in what order) for the 6
> textbook units of the Foreign Languages stream, in teaching order:
> **1 → 2 → 3 → 4 → 7 → 6**.

> **Order rationale.** This sequence is taken from the **Annual Distribution
> PDF** (priority-2 source), which prescribes the FL stream as
> *Diversity → Peace → Poverty → Tech & Innovation → Fiction or Reality? →
> Disasters & Safety* (mapped to textbook units 1 → 2 → 3 → 4 → 7 → 6).
> The textbook *Getting There* prints its units in numerical order
> (1, 2, 3, 4, 5, 6, 7, 8); the Annual Distribution overrides the
> textbook's numerical order per the Source Hierarchy in
> `../../../docs/02-source-attribution.md`.
> *If you intend "textbook order strictly" to mean the textbook's
> numerical TOC (i.e. teach Unit 6 before Unit 7), the order in this
> document must be changed — see the open question raised after Phase 2A
> commit.*

> **Source-fidelity notice (priority-4 content).**
> The per-unit *Productive language*, *Vocabulary domains*,
> *Skill focus per phase*, and *Project deliverables* tables are sourced
> directly from the official Teaching Map (priority-1) and the Annual
> Distribution (priority-2). The cross-cutting analyses
> (*"What this unit unlocks"*, *"Year-long progression arcs"*,
> *"Cumulative skills checklist"*) are **pedagogical inference** — they
> are derived from, but not literally present in, the source documents.
> Treat those analyses as `pending verification from official teaching
> map` for any high-stakes use.

## Year-long progression arcs

These arcs explain *why* the units sit in this order. Each arc shows how a
strand accumulates over the year so that the next unit can build on the
previous one.

### Grammar arc

```
U1   used to / be going to    -->   tense awareness (past <-> future)
U2   modals can/could/be able to/should/must/have to    -->   modality + ability/obligation
U3   the passive (all tenses, including modal passive)   -->   voice + register
U4   conditional types 0 and 1 + comparatives             -->   real-world hypothesis & description
U7   conditional type 3 + compound words                  -->   counterfactual reasoning
U6   reported speech (statements, questions, commands)    -->   discourse representation
```

By year-end, learners can **shift tense, voice, modality, condition and
discourse perspective** with control — all five major dimensions of the
English verb system.

### Genre arc (writing)

```
U1   descriptive paragraph (compare-contrast)
U2   biography + speech (oratorical style)
U3   instructions + press release + town code
U4   experiment report + letter asking for advice
U7   commentary + biographical account
U6   questionnaire + report with graph + safety instructions
```

By year-end, learners have produced **descriptive, narrative, instructive,
expository, argumentative, and report genres** at least once each.

### Skill arc (oral)

```
U1   describing personal preferences and predictions
U2   asking & giving opinions, polite requests, oratorical delivery
U3   pre-/while-/post-listening to a press release
U4   making suggestions, asking for & giving advice
U7   expressing regret, blame, agreement, disagreement
U6   conducting an interview, reporting results, giving advice
```

### Project artefact arc

```
U1   Life Style Profile         (personal-family scope)
U2   Nobel Prize statement      (national/international scope)
U3   Conservation Plan          (local/community scope)
U4   Experiment report          (academic/scientific scope)
U7   Miscellanies               (cultural/historical scope)
U6   Disaster preparedness      (civic/safety scope, year-capping)
```

The artefacts widen from personal → community → world, then return to
civic action — closing the circle on the syllabus theme of "engaged
citizenship".

## Unit 1 — *Signs of the Time*

| | |
|---|---|
| **Theme** | Diversity / Lifestyle change |
| **Project** | Life Style Profile (past · present · future) |
| **Duration** | 4 weeks (T1 weeks 2–5) = ~20 hours |
| **Foregrounded competencies** | C2 *(production — descriptive paragraph)* + C3 *(interpretation — anticipating from pictures, listening for gist)* |
| **Cross-cutting** | C1 (introductions, opinions on lifestyles) |

### Productive language

| Grammar | Functional language |
|---------|---------------------|
| `used to` (affirmative · negative · interrogative) for past habits | Comparing & contrasting past, present and future lifestyles |
| `be going to` for the planned / near future | Expressing certainty and doubt |
| Modals `may` / `might` / `will` for degrees of certainty | Intonation patterns when listing |
| Defining and non-defining relative clauses (with `who` / `which` / `that`) | Using techniques to avoid repetition (synonyms, opposites) |
| Present continuous for the near future | Agreeing & disagreeing with justification |

### Vocabulary domains

- **Lifestyle past**: fashion, tradition, custom, ago, food, entertainment, café, narrate, hard.
- **Lifestyle present**: modern, fast food, club, cybercafé, cable TV, surf, computers.
- **Lifestyle future**: prediction, advancement, technology, medicine.
- **Phonetics**: vowels and diphthongs, English vs. French phonetics, homophones / homonyms, final `s`.

### Skill focus per phase

| Phase | Skill focus | Anchor activity |
|-------|-------------|-----------------|
| Listen & Consider | Listening for gist + recognising `used to` | Anticipate p.16-17, *Listen & check* |
| Read & Consider | Reading for detail + relative clause patterns | *Discovering language* p.18 |
| Listening & Speaking | Speaking — describing one's own past habits | *Your turn* p.20-21 |
| Reading & Writing | Reading a model paragraph, writing date markers | *Write it up* p.22 |
| Write It Up | Guided descriptive writing (past lifestyle) | Activities 1-5 p.24-25 |
| Write It Out | Free descriptive writing (future lifestyle) | Free production p.26 |

### Project deliverables (portfolio)

1. Descriptive paragraph: "How people used to live in the past."
2. Comparison-and-contrast paragraph: present-day lifestyle.
3. Predictive paragraph: future lifestyle (with arguments and justification).
4. Picture collage representing past · present · future.

### What this unit unlocks

- Tense flexibility (past habit + future) → prerequisite for U2's modal
  ability (could / was able to) and U7's counterfactual conditional.
- Comparative / contrastive paragraph structure → reused in every later unit.

## Unit 2 — *Make Peace!*

| | |
|---|---|
| **Theme** | Peace and Conflict Resolution |
| **Project** | Statement of achievements about Nobel Peace Prize winners + UNICEF speech |
| **Duration** | 6 weeks (T1 wk 7 → T2 wk 13) = ~30 hours, the year's longest unit |
| **Foregrounded competencies** | C1 *(interaction — opinion-giving, polite requests)* + C2 *(production — biography + oratorical speech)* |
| **Cross-cutting** | C3 (interpreting pictures of peace organisations, scanning a speech) |

### Productive language

| Grammar | Functional language |
|---------|---------------------|
| Modals of ability — `can` / `could` / `be able to` / `managed to` (present, past, future, affirmative & negative) | Asking & answering Wh-questions about a reading passage |
| Modals of obligation — `must` / `mustn't` / `have to` / `don't have to` / `don't need to` / `should` / `shouldn't` | Expressing possibility, ability, permission |
| `was/were able to` (irregular form of `can`) for past achievement | Polite requests: `would you mind…`, `I wonder if you could…`, position of `please` |
| `should / shouldn't have` for retrospective criticism | Giving opinion, justifying, agreeing & disagreeing |
| Imperative for instruction; defining clauses with `which` / `what` | Reporting a speech in one's own words; oratorical style; informing, convincing, stimulating an audience |

### Vocabulary domains

- **Peace & conflict**: peace, peaceful, soldiers, horrors, warfare, World War I/II, resolve, vote, security, military action, blue helmets, hot spots.
- **Organisations & cooperation**: agencies, organisations, cooperate, leader, manager, head, principal.
- **Acronyms & abbreviations**: UN, UNICEF, UNESCO, WHO, NATO, EU.
- **Action verbs**: combat, fight, celebrate, militate, resolve.
- **Rights & freedoms**: freedom, racism, prejudice, intolerance.

### Skill focus per phase

| Phase | Skill focus | Anchor activity |
|-------|-------------|-----------------|
| Listen & Consider | *Think it over* — guessing situation, listening for verbs of representation | *Words to say* p.38 |
| Read & Consider | Reading for modal verbs in context | *Around the text*, *Practice* p.40-41 |
| Listening & Speaking | Asking & giving opinions in a dialogue | *Your turn* p.45 |
| Reading & Writing | Discriminating duties from rights → class charter | *Write it up* p.46 |
| Write It Up | Guided biography of a Nobel Peace Prize winner | *Write it up* p.47 |
| Write It Out | Free oratorical speech in defence of a peace organisation | *Write it out* p.50 |

### Project deliverables (portfolio)

1. Checklist of Nobel Prize winners over the last 10 years (with pictures).
2. Two or three short biographies + statements of achievements.
3. List of potential candidates / organisations for the next Nobel Prize.
4. Class charter of rights and duties.
5. Written speech (oratorical style) defending the candidate's nomination.

### What this unit unlocks

- Modal system mastered → prerequisite for U3 modal passive and U4
  conditional + suggestion language.
- Biography genre established → reused in U4 (inventor biography), U7
  (biographical account of an inventor), U6 (interviewee profile).
- Oratorical style established → re-anchored in U7 (commentary on misuse).

## Unit 3 — *Waste Not Want Not*

| | |
|---|---|
| **Theme** | Poverty and World Resources / Environment |
| **Project** | Conservation Plan (fact sheet · diagrams · town code · ideal-future map) |
| **Duration** | 2 weeks (T2 weeks 16–17) = ~10 hours |
| **Foregrounded competencies** | C2 *(production — instructions, press release, code of conduct)* + C3 *(interpretation — texts on the Amazon Forest and the Exxon Valdez)* |
| **Cross-cutting** | C1 (recommendations to local authorities) |

### Productive language

| Grammar | Functional language |
|---------|---------------------|
| The passive — present simple, past simple, present perfect (with modals) | Pre- / while- / post-reading scaffolds |
| The future passive (`will be + p.p.`) | Press-release register: dating, by-line, headline |
| The modal passive (`must be + p.p.`, `should be + p.p.`, `can be + p.p.`) | Writing instructions: imperative + `don't` |
| Linking words inside an instruction: `also`, `however`, `therefore` | Reordering scrambled sentences into a coherent paragraph |

### Vocabulary domains

- **Environment threats**: pollute, emission, destroy, decay, smoke, oil spill, deforestation, desertification.
- **Conservation actions**: conservation, dam, soil, forest, plant, dustbin, recycling, drinkable water, mineral resource.
- **Slogans & notices**: "A tree is life", "Green is beautiful", "Don't litter", "Plant trees".
- **Civic infrastructure**: public amenities, waste-disposal system, sewage, reservoir, salty / drinkable water.

### Skill focus per phase

| Phase | Skill focus | Anchor activity |
|-------|-------------|-----------------|
| Listen & Consider | Pre-/while-/post-reading on *The Amazon Forest* p.60 | Activities p.61–62 |
| Read & Consider | The Exxon Valdez press release (genre features) | *Write it right* p.63 |
| Listening & Speaking | Listening for the passive in a dialogue | *Your turn* p.67 |
| Reading & Writing | Guided § using the present passive | *Write it up* p.68 |
| Write It Up | Recommendations to Parliament (passive of obligation) | *Write it up* p.71 |
| Write It Out | Reordering and producing a conservation paragraph | *Write it out* p.71 |

### Project deliverables (portfolio)

1. Fact sheet of conservation measures already taken in your town.
2. Diagram + presentation of how public amenities work locally.
3. Country / town code (do's and don'ts) by category: home, school,
   forest, town.
4. Map of an ideal future village or town with symbols and a short
   descriptive caption.

### What this unit unlocks

- Passive voice fully internalised → prerequisite for U6 reported speech
  (verbs like *was said*, *has been reported*) and for any expository
  writing in 3AS (*Exploring the Past*, *Education*).
- Genre register-shifting (instruction vs. press release vs. code of
  conduct) → reused in every subsequent unit.

## Unit 4 — *Budding Scientist*

| | |
|---|---|
| **Theme** | Technology and Innovation |
| **Project** | Reports on scientific experiments + ABC of Dreams |
| **Duration** | 4 weeks (T2 weeks 18–21) = ~20 hours |
| **Foregrounded competencies** | C2 *(production — experiment report, letter asking for advice)* + C3 *(interpretation — geometry text, mobile-electrons text)* |
| **Cross-cutting** | C1 (reporting an experiment to peers, suggesting solutions) |

### Productive language

| Grammar | Functional language |
|---------|---------------------|
| Conditional type 0 (`If you heat water, it boils.`) | Stating scientific properties |
| Conditional type 1 (`If you mix x and y, you'll get z.`) | Making suggestions: `Why don't you…?`, `How about…?` |
| Comparative adjectives (`bigger`, `more powerful`) | Asking for & giving advice (`If I were you, I'd…`) |
| Conjunctions `if` / `when` / `as` linking two clauses | Asking for help / writing a letter of complaint with politeness markers |

### Vocabulary domains

- **Scientific method**: experiment, hypothesis, properties, observation,
  conclusion, conjunction, geometry, circuit, charge, electrons.
- **Lab equipment**: laboratory, apparatus, beaker, test tube, voltmeter,
  microscope, thermometer.
- **Suggestion / advice**: suggest, recommend, advise, propose.

### Skill focus per phase

| Phase | Skill focus | Anchor activity |
|-------|-------------|-----------------|
| Listen & Consider | Pre-/while-/post-reading on *Geometry* p.80 | Activities p.81 |
| Read & Consider | *Mobile electrons* text + comparative adjectives | Activities p.89 |
| Listening & Speaking | Listening to a teacher giving lab instructions | *Your turn* p.83 |
| Reading & Writing | Writing a letter to a teacher asking for guidance | *Write it up* p.88 |
| Write It Up | Guided experiment report (with conditional type 1) | Activities p.88 |
| Write It Out | Free *ABC of Dreams* | Free production |

### Project deliverables (portfolio)

1. Fact sheet describing one experiment carried out in lab.
2. Fact sheet with diagram, charts, and a short presentation of the
   experiment.
3. Letter to your teacher asking for advice on difficulties met during the
   experiment.
4. *ABC of Dreams* — alphabetic mini-essay of futurist hopes.

### What this unit unlocks

- Conditional types 0 and 1 → prerequisite for U7 conditional type 3.
- Letter-writing register → carried forward in U6 (interview report) and
  3AS U2 (policy statement, opinion article).

## Unit 7 — *Science or Fiction*

| | |
|---|---|
| **Theme** | Fiction or Reality? |
| **Project** | Miscellanies (type-3 conditional statements · dialogue · biographical commentary) |
| **Duration** | 3 weeks (T3 weeks 24–26) = ~15 hours |
| **Foregrounded competencies** | C2 *(production — commentary, biography)* + C3 *(interpretation — text on the importance of inventions)* |
| **Cross-cutting** | C1 (criticising / agreeing / disagreeing about misuse of an invention) |

### Productive language

| Grammar | Functional language |
|---------|---------------------|
| Conditional type 3 (`If computers had not been invented, …`) | Underlining the importance of an achievement |
| Modals (`should have`, `could have`, `might have`) for retrospective regret/blame | Expressing regret, blame, advice |
| Compound words (e.g. `well-known`, `hand-made`, `home-made`) | Clarifying & exemplifying with `for instance`, `that is to say` |
| Past tense + sequencers (`first`, `then`, `finally`) | Establishing chronology of events in a biography |

### Vocabulary domains

- **Inventions & discoveries**: invent, invention, discover, discovery,
  device, contraption, apparatus, breakthrough.
- **Curiosity / genius**: curiosity, genius, perspiration, eagerness,
  ambition.
- **Misuse / impact**: misuse, abuse, harm, benefit, improve, ameliorate,
  worsen.
- **Sequencers**: at first, then, after that, eventually, in the end.

### Skill focus per phase

| Phase | Skill focus | Anchor activity |
|-------|-------------|-----------------|
| Listen & Consider | Anticipating + listening to a debate on tech misuse | Activities 1–2 p.139 |
| Read & Consider | Reading a text on the importance of an invention | Activities p.140 |
| Listening & Speaking | Speaking — expressing regret about a misused invention | Activities p.146 |
| Reading & Writing | Reading a biography + chronological connectors | Activities p.149-150 |
| Write It Up | Guided commentary using type-3 conditional | Activities p.141 |
| Write It Out | Free biographical account of a scientist or inventor | Free production p.151 |

### Project deliverables (portfolio)

1. Set of "If…" type-3 statements about real inventions
   (`If computers had not been invented…`, `If vaccines had not been
   discovered…`).
2. Short dialogue about the misuse of an invention.
3. Piece of commentary about the invention.
4. Short biographical account of the inventor / scientist.

### What this unit unlocks

- Counterfactual reasoning → prerequisite for 3AS U2 *Business Ethics*
  (`if proper laws had been passed…`) and U5 *Astronomy*
  (`suppose a comet collided…`).
- Biography style consolidated (3rd time in the year, after U2 and U4).

## Unit 6 — *No Man Is an Island*

| | |
|---|---|
| **Theme** | Disasters and Safety |
| **Project** | Survey on disaster preparedness (questionnaire · interview · report with graph · set of safety instructions) |
| **Duration** | 3 weeks (T3 weeks 29–31) = ~15 hours |
| **Foregrounded competencies** | C1 *(interaction — interview, asking & giving advice)* + C2 *(production — questionnaire, report, instructions)* |
| **Cross-cutting** | C3 (skimming and scanning a passage on disasters) |

### Productive language

| Grammar | Functional language |
|---------|---------------------|
| Reported speech — present perfect, past simple, future | Reporting results: *the survey shows*, *most respondents said* |
| Reporting verbs — *say*, *tell*, *ask*, *advise*, *warn*, *suggest*, *order*, *promise* | Asking for & giving advice: *if I were you*, *you should*, *you'd better* |
| Reporting statements, questions and quotes (with punctuation) | Cause-and-effect markers: *because*, *for*, *as*, *since*, *therefore* |
| Reporting orders & requests | Pronunciation of silent letters; primary stress |

### Vocabulary domains

- **Disasters**: earthquake, flood, drought, tsunami, hurricane, cyclone,
  volcanic eruption, wildfire.
- **Mitigation & safety**: mitigation, preparedness, evacuation, shelter,
  emergency kit, drill, alarm.
- **Survey & data**: survey, questionnaire, interview, respondent,
  informant, graph, chart, statistics, percentage.
- **Advice & instruction**: should, ought to, had better, must, mustn't,
  please.

### Skill focus per phase

| Phase | Skill focus | Anchor activity |
|-------|-------------|-----------------|
| Listen & Consider | *Discovering language* — direct → reported speech | *Grammar Desk* p.121 |
| Read & Consider | Reading + reporting verbs | Activities p.123 |
| Listening & Speaking | Conducting a short interview on disaster preparedness | *Your turn* p.125 |
| Reading & Writing | Writing a short report with a graph | Activities p.130 |
| Write It Up | Guided report + reporting verbs | Activities p.130-131 |
| Write It Out | Set of safety instructions for an earthquake | *Write it out* p.131 |

### Project deliverables (portfolio)

1. Short questionnaire (5–10 items) on disaster preparedness.
2. Two short interview transcripts (with classmates / family members).
3. Report of the survey results, including a graph and a brief
   interpretation.
4. Set of safety instructions to mitigate one specific disaster
   (earthquake, flood, fire).

### What this unit unlocks (year-end consolidation)

- Reported speech — final major grammar piece of the year, reused
  extensively in 3AS *(Education, Astronomy, Feelings & Emotions)*.
- Survey-and-report genre — a generative literacy that can be reapplied to
  any 3AS topic.

## Cumulative skills checklist (for end-of-year report card)

By the end of 2AS Foreign Languages, the learner can:

### Listening (C3 — Interpretation)
- [ ] Anticipate the topic of an oral text from pictures, title and key words
- [ ] Listen for gist (main idea) in a dialogue or a press release
- [ ] Listen for detail (specific information) in an interview or a speech
- [ ] Distinguish direct from reported speech in an oral narrative
- [ ] Recognise stress, intonation patterns, and silent letters

### Speaking (C1 — Interaction)
- [ ] Introduce oneself and describe one's habits and lifestyle
- [ ] Ask and give opinions, justifying with at least one reason
- [ ] Make polite requests using the appropriate modal forms
- [ ] Conduct a short interview using prepared questions
- [ ] Deliver a short speech in an oratorical style

### Reading (C3 — Interpretation)
- [ ] Skim a passage for the main idea
- [ ] Scan a passage for specific information
- [ ] Infer meaning of unknown words from context
- [ ] Identify discourse markers and reasoning patterns
- [ ] Read a graph, chart, or diagram and report its content

### Writing (C2 — Production)
- [ ] Write a descriptive paragraph (compare-contrast)
- [ ] Write a short biography
- [ ] Write a press release / short report with a graph
- [ ] Write an experiment report
- [ ] Write a letter (formal: enquiry, complaint, advice request)
- [ ] Write a commentary using counterfactual reasoning
- [ ] Write a set of instructions (imperative, do's and don'ts)
- [ ] Write a short oratorical speech
