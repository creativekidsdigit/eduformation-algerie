# 2AS — Foreign Languages — Competency Map

> Year-long view of how the three communicative competencies (C1 / C2 / C3)
> and the six Bloom's levels are distributed across the 6 units, so that
> teachers can verify balance, identify over- or under-served strands, and
> intervene with differentiation where needed.

> **Source-fidelity notice (priority-4 content).**
> The unit-by-unit **C1 / C2 / C3 tags** below are sourced directly from
> the official Teaching Map's per-unit aim sections. The
> **emphasis weighting** (★★★ / ★★ / ★) and the **Bloom's-level mapping**
> are *pedagogical inference* — the source labels each unit's
> competencies but does not weight them or map them to Bloom's. Treat
> the star ratings and Bloom's columns as `pending verification from
> official teaching map`. The Productive-language map's
> *Final mastery target* column and the *Differentiation hooks* table are
> likewise pedagogical inference.

## The three competencies (recap)

| Code | Name | Definition (per official Teaching Map) |
|------|------|----------------------------------------|
| **C1** | Interaction | Negotiates meaning live in oral or written exchanges |
| **C2** | Production | Produces an extended, organised oral or written text |
| **C3** | Interpretation | Extracts, infers and interprets meaning from input |

Source: every unit page of the Teaching Map labels its aims with C1 / C2 /
C3. We preserve the same labelling here.

- Every unit's project sits in **C2 (Production)** — that is correct,
  Backward Design Stage 2 demands an extended-text artefact. ✔
- **C1 (Interaction)** is foregrounded in **U2 *Make Peace!*** (opinion +

  competency. ✔
- **C3 (Interpretation)** is consistently strong-secondary; no unit
  ignores it. The "Listen & Consider" + "Read & Consider" phases
  guarantee at least 2 C3 lessons per unit. ✔

## Bloom's progression per unit

Bloom's coverage: ✓ = at least one objective at this level inside the unit.
Bold ✓ = the unit's *culminating* level (the project).

| # | Unit | Remember | Understand | Apply | Analyse | Evaluate | **Create** |
|---|------|----------|------------|-------|---------|----------|------------|
| 1 | Signs of the Time | ✓ | ✓ | ✓ | ✓ | ✓ | **✓** |
| 2 | Make Peace! | ✓ | ✓ | ✓ | ✓ | ✓ | **✓** |
| 3 | Waste Not Want Not | ✓ | ✓ | ✓ | ✓ | ✓ | **✓** |
| 4 | Budding Scientist | ✓ | ✓ | ✓ | ✓ | ✓ | **✓** |
| 7 | Science or Fiction | ✓ | ✓ | ✓ | ✓ | ✓ | **✓** |
| 6 | No Man Is an Island | ✓ | ✓ | ✓ | ✓ | ✓ | **✓** |

Every unit traverses the full Bloom's pyramid because every unit ends in a
**Create**-level project. The intermediate levels are evidenced by:

- **Remember** — vocabulary glossary recall in *Listen & Consider*.
- **Understand** — gist & detail comprehension in reading and listening.
- **Apply** — *Practice* phase: gap-fills, transformation drills, role-plays.
- **Analyse** — *Stop & Consider* / *Discovering language*: comparing past
  vs. present, direct vs. reported, active vs. passive.
- **Evaluate** — *Your turn*: opinion-giving, peer review, self-assessment
  using the project rubric.
- **Create** — the unit project itself.

## Skills × Competencies cross-table

How the four language skills map to the three competencies in this stream.

| Skill | Primary competency | Secondary competency | Where exercised |
|-------|--------------------|-----------------------|-----------------|
| Listening | C3 | C1 | *Listen & Consider* phase, *Listening & Speaking* phase |
| Speaking | C1 | C2 | *Listening & Speaking*, project oral delivery |
| Reading | C3 | C2 | *Read & Consider*, *Reading & Writing*, exam Section 1 |
| Writing | C2 | C1 | *Write It Up*, *Write It Out*, project artefact, exam Section 3 |

Every lesson plan in `../lesson_plans/` will include a row in its
alignment matrix that names the skill, the primary competency, and the
Bloom's level — so that this distribution can be verified empirically at
the end of each trimester.

## Productive-language map (year-spanning)

| Grammar / functional item | Introduced in | Recycled in | Final mastery target |
|---------------------------|----------------|-------------|----------------------|
| `used to` (past habit) | U1 | U7 (in commentary), U2 (in biography) | Apply |
| `be going to` (planned future) | U1 | — | Understand → Apply |
| Defining / non-defining relative clauses | U1 | U2 (definitions), U3 (waste types) | Apply |
| Modals of ability — `can`, `could`, `be able to`, `managed to` | U2 | U7 (regret with `could have`) | Apply → Analyse |
| Modals of obligation — `must`, `have to`, `should`, `mustn't`, `don't have to` | U2 | U3 (passive of obligation), U6 (advice) | Apply → Evaluate |
| Polite requests — `would you mind`, `I wonder if you could` | U2 | U4 (asking for help), U6 (interview) | Apply |
| Reporting a speech | U2 (intro) | U6 (full reported speech) | Understand → Apply |
| The passive — present, past, present perfect | U3 | U6 (in reports) | Apply → Create |
| The future passive | U3 | — | Apply |
| The modal passive | U3 | U6 (safety instructions) | Apply |
| Conditional type 0 | U4 | — | Apply |
| Conditional type 1 | U4 | U6 (preparedness advice) | Apply |
| Comparative adjectives | U4 | U7 (compound adjectives) | Apply |
| Conditional type 3 | U7 | — | Apply → Analyse |
| Compound words | U7 | — | Understand → Apply |
| Reporting verbs (`say`, `tell`, `ask`, `advise`, `warn`, `suggest`) | U6 | — | Apply → Create |
| Reported statements / questions / orders | U6 | — | Apply → Create |

The verbs in the *Final mastery target* column are Bloom's level verbs.
A learner reaching Apply on most rows and Analyse / Create on the
high-leverage rows (modals, passive, reported speech) is on track for
3AS.

## QA self-check (before each unit is taught)

Before opening the first lesson of a unit, the teacher confirms:

- [ ] **All three competencies** are touched in this unit. (See the
      emphasis table above.)
- [ ] **All six Bloom's levels** are touched, with **Create** anchored by
      the project artefact. (See the Bloom's table.)
- [ ] **All four skills** are exercised at least once in this unit.
- [ ] **At least one differentiation hook** is selected for each profile
      (struggling / ADHD-friendly / advanced / inclusive).
- [ ] **The project rubric** has been shared with learners *before* the
      unit begins (Six A's, Assessment Practices gate).

If any box is unchecked, the unit is not ready to teach. Replace the
missing item before opening the first lesson.
