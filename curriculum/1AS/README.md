# 1AS — First Year Secondary

**Textbook:** *At the Crossroads*
**Streams:** Common Core Sciences & Tech (3 h/wk, 81 h, coef 2) · Common Core Letters (4 h/wk, 108 h, coef 3)
**Number of units:** 5

| # | Unit | Theme | Project |
|---|------|-------|---------|
| 1 | Getting Through | Intercultural Exchanges | Job application booklet |
| 2 | Once Upon a Time | Famous People (literature) | Book review |
| 3 | Our Findings Show | Communication: The Press | Survey + report with graph |
| 4 | Eureka | Innovation and Technology | Invention profile |
| 5 | Back to Nature | Environment / Pollution / Animals | Consumer guide |

## Folder layout

- `annual_plan/` — yearly plan, scope & sequence, pacing, assessment calendar, competency map.
- `unit_plans/` — one overview per unit (Stage 1 + Stage 2 of Backward Design).
- `lesson_plans/` — full lesson plans with ESA flow & timing.
- `assessments/` — diagnostic, formative tools, unit tests, trimester exams.
- `rubrics/` — analytic rubrics for reading, writing, listening, speaking and the unit projects.
- `worksheets/` — student handouts.
- `teacher_guide/` — teaching notes, baseline, classroom implementation tips.
- `answer_keys/` — keys for every assessment and worksheet.
