## Listing-platform-specific notes

### Etsy
- **Title:** use the 140-char version
- **Tags:** all 13 (Etsy allows exactly 13)
- **Description:** use the Etsy version (more emoji-rich, more scannable)
- **Files:** upload PDF only (Etsy buyers expect a single download)
- **Categories:** Craft Supplies & Tools → Patterns & How To → Printables → Educational

### Payhip
- **Title:** can be longer; same as Etsy works fine
- **Description:** use the Payhip version (cleaner, less emoji)
- **Files:** PDF only
- **Tags / categories:** Education → Lesson plans / Printables

### Teachers Pay Teachers
- **Title:** TPT allows 70 chars in title — trim to: `2AS English [Pack name] | Algeria CBA PDP Lesson Plan + Worksheets`
- **Description:** can re-use the Etsy version; expand "What's Included" into a numbered list
- **Tags / standards:** TPT-specific dropdowns (Grade: 11–12; Subject: ESL/ELL; Resource Type: Worksheets · Lesson Plans · Printables)
- **Pricing:** ~ 5–10 % lower than Etsy due to TPT's discount-heavy norms
