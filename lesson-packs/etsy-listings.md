## Listing checklist (before you publish)

- [ ] Replace `[Your Name / Brand]` placeholder at the bottom of each pack with your real brand name.
- [ ] Export each `.md` to PDF (e.g. `pandoc <file>.md -o <file>.pdf` or paste into Google Docs → Download → PDF).
- [ ] Add a cover image / thumbnail for each listing (Canva templates work well).
- [ ] Set delivery as "instant download" on Etsy / Payhip.
- [ ] Add 4–6 preview images per listing (cover · sample lesson plan · sample worksheet · sample rubric · sample answer key).
- [ ] Tag all 3 products with `2AS English`, `Algeria ESL`, `printable PDF` for cross-discovery.
- [ ] Set up the bundle as a separate listing if you want to drive the higher AOV.
